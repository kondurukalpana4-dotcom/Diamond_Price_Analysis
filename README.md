# Diamond Price Analysis

## Objective
Analyze how different features influence diamond prices using Exploratory Data Analysis (EDA).

## Dataset
Diamonds Dataset (Kaggle)

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Statistics
- Data Visualization
- EDA

## Tasks Performed
- Loaded the dataset using Pandas
- Explored the dataset
- Handled missing values and duplicate records
- Detected outliers
- Analyzed categorical and numerical features
- Calculated statistical measures
- Performed correlation analysis
- Created visualizations:
  - Bar chart
  - Line chart
  - Histogram
  - Scatter plot

## Key Insights
- Diamond price increases with carat value.
- Cut, color, and clarity affect diamond pricing.
- Correlation analysis helped identify relationships between numerical features.

## Conclusion
This project helped in understanding data cleaning, exploratory data analysis, statistics, correlation, and visualization using Python.
